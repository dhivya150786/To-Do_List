# project5

Simple To-Do List Web App

This is a basic To-Do List application built using HTML, CSS, and JavaScript. It allows users to add tasks and remove them dynamically without reloading the page.

 Features
Add new tasks using an input field
Delete individual tasks
Prevents empty task submission
Simple and clean user interface
Runs entirely in the browser (no backend required)

 Technologies Used
HTML – Structure of the app
CSS – Basic styling (inline styles)
JavaScript – DOM manipulation and event handling


File Structure

index.html
All HTML, CSS, and JavaScript are included in a single file.

 How It Works
Enter a task in the input box.


Click the Add button.


The task appears in a list below.


Click Delete to remove a task.


The app uses JavaScript to:


Read input values


Create list items dynamically


Attach delete functionality to each task


▶️ How to Run


Download or copy the HTML file.


Open it in any modern web browser (Chrome, Edge, Firefox, etc.).


Start adding tasks!


No installation or setup required.
